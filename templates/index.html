PASO 1 — Comprobar Git

Primero comprobamos que Git exista en Termux.

pkg update
pkg install git
git --version

PASO 2 — Elegir carpeta del proyecto

Esta ruta manda. La app ejecutará Git exactamente aquí; no usará la carpeta donde está instalada la web.

PASO 3 — Inicializar Git

Equivale a ejecutar git init dentro de la carpeta.

cd {{ repo_path }}
git init

PASO 4 — Configurar identidad

Estos datos se guardan dentro de este repositorio, igual que usando git config --local en Termux.

PASO 5 — Conectar repositorio de GitHub

Crea el repositorio vacío en GitHub y pega aquí su URL HTTPS.

git remote add origin https://github.com/USUARIO/REPOSITORIO.git

PASO 6 — Preparar archivos

Ahora añadimos todos los archivos con git add ..

git add .

PASO 7 — Crear el commit

El commit guarda una versión de los cambios preparados.

git commit -m "Tu mensaje"

PASO 8 — Establecer la rama main

Dejamos la rama principal con el nombre main.

git branch -M main

PASO 9 — Push a GitHub

Último paso: subimos la rama main. El token se usa solo durante este Push y no se guarda en el remoto.

git push -u origin main
