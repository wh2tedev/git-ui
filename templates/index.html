    Comprobar Git

    Primero comprobamos que Git exista en Termux.

    pkg update && pkg install git
git --version

    Inicializar el repositorio

    Esto ejecuta git init exactamente en , sin depender de dónde esté instalada esta app.

    git init

    Configurar identidad

    Se guarda dentro de este repositorio, como git config --local.

    Conectar con GitHub

    Crea el repositorio vacío en GitHub y pega aquí su URL HTTPS. Puedes hacerlo más tarde desde Configuración si aún no lo tienes.
